# 出片手账 · 产品定位与情绪价值主张

## 1. 产品一句话
把日常小确幸“可爱出片 + 温柔记录”做成手账，三步生成可发朋友圈/小红书的图文，持续提供情绪价值与自我鼓励。

## 2. 目标人群
- 年龄：12–20 岁为主（未成年人友好），也覆盖喜爱手帐风的年轻女性
- 需求：
  - 低门槛出片（模板、贴纸、花字，一键生成）
  - 情绪记录与反馈（表情/色卡打卡、每日鼓励）
  - 可爱而安全的私密空间（本地加密/上锁，最小社交暴露）

## 3. 情绪价值主张（核心）
- 即刻满足：一键套模板“变好看”，获得正向反馈与成就感
- 温柔陪伴：每日一句、自我肯定卡片、轻负担的情绪打卡
- 安全掌控：私密可控、无压力的“只给自己看也很美好”

## 4. 差异化
- 聚焦“情绪价值”的出片：模板与贴纸围绕情绪主题（治愈/元气/温柔/梦幻）
- 记录即素材：情绪打卡自动生成可发布的手账卡片
- 低打扰、轻 KPI：去除强行连续打卡惩罚，使用“温柔鼓励”与可爱反馈

## 5. 平台与合规
- iOS 原生（iOS 15+），中文优先
- 本地数据优先存储，可选 iCloud 同步
- 未成年人保护、隐私策略见 `privacy_safety.md`
