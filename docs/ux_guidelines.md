# 视觉与交互规范（温柔设计）

## 设计原则
- 温柔：浅饱和配色、留白、圆角、柔和动效（<200ms）
- 低负担：路径≤3 步、默认值合理、可跳过
- 正向反馈：完成即给“可爱反馈/彩虹屁”，无惩罚
- 安全可控：显著的上锁与删除入口，清晰确认

## 配色与字体
- 主题色：治愈绿/樱花粉/奶油黄（主题包）
- 文本：中文默认苹方，标题 18–22，正文字号 14–16
- 图标：线性/圆角，视觉统一

## 组件规范
- 模板卡：封面图 + 风格标签 + 比例标记
- 情绪选择：5 个表情 + 色卡（大触区）
- 导出按钮：固定底部安全区，显著可见
- 上锁：设置页一级入口，支持“立即上锁”

## 可访问性
- 字体放大适配；对比度符合 WCAG AA
- 低动效模式
