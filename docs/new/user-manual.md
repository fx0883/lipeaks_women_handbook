# 出片手账 用户使用说明

## 📖 文档信息
- **版本**: v1.0
- **适用版本**: 出片手账 Vue 3 Web版
- **目标用户**: 12-20岁小女生及喜爱手帐风的年轻女性
- **更新时间**: 2024-01-20

## 🎯 产品简介

"出片手账"是一款专为小女生设计的Web应用，让你能够轻松创建精美的图文内容。通过可爱的模板、温暖的色彩和简单的操作，记录生活中的美好瞬间，生成可发朋友圈/小红书的精美图文。

### ✨ 核心特色
- **一键出片**: 选择模板，替换内容，瞬间生成精美图文
- **情绪记录**: 记录每日心情，生成治愈系情绪卡片
- **主题切换**: 6种预设主题色，满足不同心情需求
- **私密安全**: 本地存储，保护你的隐私
- **简单易用**: 三步完成，无需复杂操作

## 🚀 快速开始

### 首次使用
1. **打开网站**: 在浏览器中访问出片手账网站
2. **选择主题**: 点击右上角主题按钮，选择喜欢的主题色
3. **开始创作**: 点击"开始创作"按钮，选择模板开始制作

### 界面概览
- **顶部导航**: 网站标题、主题切换、设置入口
- **侧边栏**: 功能导航（首页、情绪打卡、相册、设置）
- **主内容区**: 模板展示、编辑器、预览区域
- **底部**: 帮助链接、关于信息

## 📱 功能详解

### 1. 一键出片功能

#### 1.1 选择模板
**使用场景**: 想要制作精美的图文内容

**详细步骤**:
1. **进入首页**: 点击侧边栏的"首页"或网站标题
2. **浏览模板**: 在模板网格中浏览各种精美模板
3. **筛选模板**: 
   - 点击分类标签（日常、情绪、回忆、特殊）
   - 使用搜索框搜索特定模板
   - 查看"热门"和"最新"标签
4. **预览模板**: 鼠标悬停在模板上查看预览效果
5. **选择模板**: 点击心仪的模板进入编辑器

**模板分类说明**:
- **日常类**: 适合记录日常生活、心情日记
- **情绪类**: 专门为情绪表达设计的模板
- **回忆类**: 适合记录重要时刻、美好回忆
- **特殊类**: 生日、节日等特殊场合的模板

#### 1.2 编辑内容
**使用场景**: 个性化定制模板内容

**详细步骤**:
1. **上传图片**:
   - 点击图片区域或"添加图片"按钮
   - 选择本地图片文件（支持JPG、PNG格式）
   - 最多可添加9张图片
   - 拖拽调整图片顺序

2. **编辑文字**:
   - 点击文字区域进行编辑
   - 标题限制30字以内
   - 副标题限制50字以内
   - 支持换行和特殊符号

3. **添加贴纸**:
   - 点击"贴纸"按钮打开贴纸库
   - 选择喜欢的贴纸（最多20个）
   - 拖拽调整贴纸位置和大小
   - 点击贴纸可删除

4. **应用滤镜**:
   - 点击"滤镜"按钮选择滤镜效果
   - 6种滤镜可选：暖色、冷色、奶油、胶片、清透、黑白
   - 实时预览滤镜效果

5. **调整花字**:
   - 选择文字后点击"花字"按钮
   - 选择字体样式（6种可爱字体）
   - 调整字号（12-48px）
   - 选择颜色（8种预设色）
   - 设置对齐方式（左对齐、居中、右对齐）

#### 1.3 导出作品
**使用场景**: 保存和分享制作的作品

**详细步骤**:
1. **预览效果**: 在右侧预览区域查看最终效果
2. **选择格式**: 点击"导出"按钮，选择PNG或JPG格式
3. **设置分辨率**: 系统自动设置为短边1080px高清分辨率
4. **下载保存**: 点击"保存"按钮，作品自动下载到本地
5. **分享使用**: 可直接用于朋友圈、小红书等社交平台

### 2. 情绪打卡功能

#### 2.1 记录情绪
**使用场景**: 记录每日心情，生成情绪卡片

**详细步骤**:
1. **进入情绪打卡**: 点击侧边栏的"情绪打卡"
2. **选择情绪**:
   - 点击情绪表情（😊开心、🤩兴奋、😌平静、😢难过、😠生气）
   - 选择情绪强度（1-10级滑块）
3. **选择颜色**: 点击情绪色卡，选择对应的情绪颜色
4. **添加描述**: 
   - 在文字框中输入今日心情描述（≤120字）
   - 添加相关标签（如：朋友、购物、开心）
5. **上传图片**（可选）: 添加一张与心情相关的图片
6. **保存记录**: 点击"保存"按钮完成情绪记录

#### 2.2 查看情绪日历
**使用场景**: 回顾情绪变化，了解心情趋势

**详细步骤**:
1. **进入情绪日历**: 点击侧边栏的"情绪日历"
2. **查看月度视图**: 
   - 日历上显示每日情绪色块
   - 不同颜色代表不同情绪
   - 颜色深浅表示情绪强度
3. **查看详情**: 点击某一天查看详细情绪记录
4. **情绪统计**: 查看月度情绪分布和趋势
5. **导出情绪卡片**: 点击某天的情绪记录，生成情绪手账卡片

### 3. 主题切换功能

#### 3.1 选择预设主题
**使用场景**: 根据心情或喜好更换应用主题色

**详细步骤**:
1. **打开主题设置**: 点击右上角主题按钮或进入设置页面
2. **浏览主题**: 查看6种预设主题：
   - **粉色梦境**: 温柔浪漫的粉色系
   - **紫色幻想**: 神秘优雅的紫色系
   - **薄荷清新**: 清新自然的薄荷绿
   - **桃子温暖**: 温暖治愈的桃子色
   - **薰衣草温柔**: 温柔淡雅的薰衣草
   - **珊瑚日落**: 活力四射的珊瑚色
3. **预览效果**: 鼠标悬停在主题上查看预览
4. **应用主题**: 点击选择主题，系统立即切换
5. **收藏主题**: 点击心形图标收藏喜欢的主题

#### 3.2 自定义主题
**使用场景**: 创建专属的个人主题色

**详细步骤**:
1. **进入自定义**: 在主题选择页面点击"自定义主题"
2. **选择主色调**: 使用颜色选择器选择喜欢的主色调
3. **预览效果**: 系统自动生成配套的辅助色
4. **保存主题**: 输入主题名称，点击"保存"
5. **应用主题**: 新主题自动添加到收藏列表

### 4. 相册管理功能

#### 4.1 查看作品
**使用场景**: 管理所有创作的作品

**详细步骤**:
1. **进入相册**: 点击侧边栏的"相册"
2. **浏览作品**: 以网格形式查看所有作品
3. **筛选作品**:
   - 按模板类型筛选
   - 按创建日期筛选
   - 按标签筛选
4. **搜索作品**: 使用搜索框按标题或标签搜索
5. **查看详情**: 点击作品查看详细信息

#### 4.2 管理作品
**使用场景**: 整理和删除不需要的作品

**详细步骤**:
1. **选择作品**: 点击作品进入选择模式
2. **批量操作**:
   - 选择多个作品
   - 点击"批量删除"或"批量导出"
3. **单个操作**:
   - 点击作品右上角菜单
   - 选择编辑、删除、导出等操作
4. **回收站**: 删除的作品进入回收站，7天内可恢复
5. **永久删除**: 在回收站中永久删除作品

### 5. 每日一句功能

#### 5.1 查看每日一句
**使用场景**: 获得每日正能量和鼓励

**详细步骤**:
1. **进入每日一句**: 在首页或设置页面查看
2. **阅读内容**: 查看今日推荐的自我肯定语句
3. **收藏语句**: 点击心形图标收藏喜欢的语句
4. **分享语句**: 点击分享按钮分享到社交平台

#### 5.2 情绪推荐
**使用场景**: 根据当前情绪获得相关鼓励

**详细步骤**:
1. **完成情绪打卡**: 先记录当前情绪
2. **查看推荐**: 系统根据情绪推荐相关语句
3. **选择语句**: 从推荐列表中选择喜欢的语句
4. **应用到作品**: 将语句添加到创作的作品中

### 6. 设置与安全

#### 6.1 应用设置
**使用场景**: 个性化应用设置

**详细步骤**:
1. **进入设置**: 点击侧边栏的"设置"
2. **主题设置**: 管理主题色和个性化设置
3. **通知设置**: 设置每日提醒和通知
4. **语言设置**: 选择界面语言（中文/英文）
5. **字体设置**: 调整界面字体大小

#### 6.2 隐私安全
**使用场景**: 保护个人隐私和数据安全

**详细步骤**:
1. **应用锁定**: 
   - 设置应用密码
   - 启用指纹/面容识别（移动端）
2. **数据管理**:
   - 查看数据使用情况
   - 导出个人数据备份
   - 清除缓存数据
3. **隐私设置**:
   - 设置作品可见性
   - 管理分享权限

## 🎨 使用技巧

### 1. 模板选择技巧
- **日常记录**: 选择简约的日常类模板
- **情绪表达**: 使用色彩丰富的情绪类模板
- **重要时刻**: 选择精美的回忆类模板
- **特殊场合**: 使用应景的特殊类模板

### 2. 色彩搭配建议
- **温暖心情**: 选择粉色、橙色等暖色调
- **平静时光**: 使用蓝色、绿色等冷色调
- **活力四射**: 选择鲜艳的彩虹色系
- **温馨治愈**: 使用柔和的米色、薰衣草色

### 3. 文字编辑技巧
- **标题简洁**: 控制在10-15字，突出重点
- **副标题补充**: 添加细节描述，增加趣味性
- **情感表达**: 使用emoji和特殊符号增加活力
- **字体搭配**: 标题用粗体，正文用常规字体

### 4. 图片处理建议
- **图片质量**: 选择清晰、光线充足的照片
- **构图技巧**: 注意主体突出，背景简洁
- **色彩协调**: 图片色调与模板主题保持一致
- **数量控制**: 1-3张图片效果最佳

## 🔧 常见问题

### Q1: 如何选择合适的模板？
**A**: 根据使用场景选择：
- 日常记录选择简约模板
- 情绪表达选择色彩丰富的模板
- 重要时刻选择精美模板
- 特殊场合选择应景模板

### Q2: 可以自定义主题色吗？
**A**: 可以！除了6种预设主题，还支持自定义主题色：
1. 进入主题设置
2. 点击"自定义主题"
3. 选择喜欢的主色调
4. 保存并应用

### Q3: 如何保护隐私？
**A**: 多种隐私保护方式：
- 设置应用密码锁定
- 作品默认仅自己可见
- 数据仅存储在本地
- 支持数据导出备份

### Q4: 可以导出哪些格式？
**A**: 支持PNG和JPG两种格式：
- PNG格式：无损压缩，适合高质量需求
- JPG格式：文件较小，适合网络分享
- 分辨率：短边1080px，确保清晰度

### Q5: 如何管理作品？
**A**: 通过相册功能管理：
- 网格展示所有作品
- 支持分类筛选和搜索
- 批量删除和导出
- 回收站7天内可恢复

### Q6: 情绪打卡有什么作用？
**A**: 情绪打卡帮助：
- 记录每日心情变化
- 生成治愈系情绪卡片
- 查看情绪趋势统计
- 获得情绪相关鼓励
