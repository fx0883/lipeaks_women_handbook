# MVP 规格与验收标准

版本: v0.1 (MVP)
目标: 三步出片 + 情绪打卡 + 私密保存，7 天内可用的最小集合。

## 一、MVP 范围 (Must)
1) 一键出片
- 模板库: 12 款内置模板 (3 套风格 x 4 比例 1:1 / 4:5 / 9:16 / 3:4)
- 内容替换: 图片(最多9张) / 标题 / 副标 / 日期 / 贴纸
- 滤镜: 6 种常用滤镜 (暖/冷/奶油/胶片/清透/黑白)
- 花字: 6 种可爱字体(内置), 字号/行距/颜色可调
- 导出: PNG/JPG(可选), 分辨率短边 1080px, 保存相册

2) 情绪打卡
- 打卡: 表情 5 档 + 颜色卡 + 短句(可选)
- 日历: 按日显示情绪色块
- 自动出片: 打卡后生成「情绪手账卡片」(可直接分享)

3) 私密与安全
- App 上锁: FaceID/TouchID/数字密码
- 本地存储: 默认仅本地，可选 iCloud 同步(默认关闭)
- 快速删除: 长按卡片删除，回收站 7 天可恢复

4) 每日一句（自我肯定）
- 120 条内置肯定句，随机/按情绪推荐
- 每天 1 次提醒 (静默/横幅可选)

## 二、导航与流程
- 首启: 权限引导(相册) -> 选择主题包 -> 教程 3 步
- Tab: 出片 | 打卡 | 相册 | 我的
- 出片: 选模板 -> 换图/文字/贴纸 -> 滤镜/花字 -> 导出
- 打卡: 选表情 -> 颜色 -> 句子(可选) -> 存 -> 生成卡片

## 三、验收标准 (DoD)
- 12 模板 10 秒内完成渲染预览（中端机型）
- 连续导出 5 次不崩溃，峰值内存 < 600 MB（iPhone 11）
- 打卡完成 1 秒内生成情绪卡片
- 后台返回需二次验证（可设 30 秒延时）
- 离线可用（模板/贴纸/字体本地化）

## 四、非功能性
- iOS 15+，深浅色一致
- 文案友好，未成年人可理解
- 首版无追踪 SDK，可选崩溃统计

## 五、出片内容规范
- 模板: JSON 结构化(见 data_model.md)
- 文本: 不超 120 字，自动缩放/换行
- 图片: HEIC/JPG/PNG 输入；导出统一 sRGB

## 六、留白(Should/Nice)
- 图标/主题包切换
- 模板市场
- 自定义贴纸上传

## 七、风险与依赖
- 字体/贴纸商用授权
- 未成年人保护与隐私条款上线前核对
