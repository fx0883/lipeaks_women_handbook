# 用户故事与用例流程（MVP）

## 角色
- A：小龄女生用户（初中/高中）
- B：大学女生/年轻女性

## 核心故事
1. 作为用户，我想用一张/多张照片一键生成可爱手账，方便我发朋友圈/小红书。
   - 验收：选择模板->替换内容->导出；3 步内完成。
2. 作为用户，我想每天用表情和颜色快速记录心情，并看到漂亮的情绪卡片。
   - 验收：≤10 秒完成打卡；自动生成卡片可保存/分享。
3. 作为用户，我需要把应用上锁，确保别人看不到我的内容（Web 版）。
   - 验收：重回页面或空闲后需验证；支持密码上锁。
4. 作为用户，我想收到每日一句温柔鼓励，提升心情。
   - 验收：每天固定时段 1 条通知；可静默。

## 关键用例流程
- 出片
  1) 打开出片 -> 选模板 -> 替换图/文/贴纸 -> 滤镜 -> 预览 -> 导出
- 情绪打卡
  1) 打开打卡 -> 选表情 -> 选颜色 -> 选/随机句子 -> 保存 -> 生成卡片
- 上锁
  1) 我的 -> 隐私与安全 -> 开启上锁 -> 设置验证方式
- 每日一句
  1) 我的 -> 提醒 -> 开启“每日一句” -> 设定时间段
