# 出片手账 App 需求文档索引

本目录包含“出片手账”面向小年龄女生、突出情绪价值的最小可行产品（MVP）需求与迭代规划。

文档列表（按优先阅读顺序）：
- `product_brief.md` 产品定位与情绪价值主张（已对齐 Web 首版）
- `mvp_spec.md` MVP 范围、功能清单与验收标准（核心，Web 首版）
- `user_stories.md` 关键用户故事与用例流程
- `ux_guidelines.md` 视觉/交互规范与“温柔设计”原则
- `privacy_safety.md` 隐私、安全与未成年人保护（Web 首版）
- `data_model.md` 本地数据模型与模板/贴纸规范
- `notification_and_widgets.md` 通知与小组件规格
- `metrics.md` 目标指标与埋点
- `iteration_plan.md` 迭代路线图与风险

实施建议：优先严格对齐 `mvp_spec.md`（Web 首版）与 `docs/new/*` 完成开发，自测与验收均以其为准；其余文档为并行参考与后续迭代依据。
