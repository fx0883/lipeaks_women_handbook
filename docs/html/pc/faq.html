👤 账号问题

如何注册出片手账账号？

+

注册出片手账账号非常简单：

  1. 下载并打开出片手账应用
  2. 点击"注册"按钮
  3. 输入手机号或邮箱地址
  4. 设置密码和昵称
  5. 完成验证即可开始使用

忘记密码怎么办？

+

如果忘记密码，可以通过以下方式重置：

  • 在登录页面点击"忘记密码"
  • 输入注册时的手机号或邮箱
  • 获取验证码并输入
  • 设置新密码

如何修改个人资料？

+

修改个人资料的步骤：

  1. 进入"我的"页面
  2. 点击"个人资料"
  3. 修改头像、昵称、个性签名等
  4. 点击"保存"完成修改

⚡ 功能使用

如何使用一键出片功能？

+

一键出片功能使用步骤：

  1. 在"出片"页面浏览模板
  2. 选择喜欢的模板点击进入
  3. 编辑文字、添加贴纸、调整滤镜
  4. 预览效果满意后点击"导出"
  5. 选择保存到相册或分享给朋友

情绪打卡有什么作用？

+

情绪打卡功能的作用：

  • 记录每日情绪变化，了解自己的情绪模式
  • 通过情绪日历查看长期情绪趋势
  • 帮助识别情绪触发因素
  • 培养情绪觉察能力
  • 为心理健康提供数据支持

如何生成情绪卡片？

+

生成情绪卡片的步骤：

  1. 进入"打卡"页面，选择"生成卡片"
  2. 选择卡片模板和风格
  3. 选择情绪表情和颜色
  4. 输入或选择文字内容
  5. 调整字体、大小、装饰等
  6. 预览效果后下载或分享

🔧 技术问题

应用闪退怎么办？

+

如果应用出现闪退，可以尝试以下解决方法：

  • 重启应用
  • 检查设备存储空间是否充足
  • 更新应用到最新版本
  • 重启设备
  • 如果问题持续，请联系客服

图片上传失败怎么办？

+

图片上传失败的常见原因和解决方法：

  • 检查网络连接是否稳定
  • 确认图片格式是否支持（JPG、PNG等）
  • 检查图片大小是否超过限制
  • 尝试重新上传
  • 如果问题持续，请检查应用权限设置

数据同步失败怎么办？

+

数据同步失败的解决方法：

  1. 检查网络连接
  2. 确认账号登录状态
  3. 尝试手动同步
  4. 检查存储空间
  5. 重启应用

🔒 隐私安全

我的数据安全吗？

+

我们非常重视用户数据安全：

  • 所有数据都经过加密存储
  • 支持本地存储，数据不上传服务器
  • 提供应用锁功能保护隐私
  • 支持数据导出和删除
  • 严格遵守隐私政策和数据保护法规

如何设置应用锁？

+

设置应用锁的步骤：

  1. 进入"我的"页面
  2. 选择"隐私设置"
  3. 开启"应用锁"功能
  4. 设置锁屏密码或指纹
  5. 每次打开应用都需要验证

可以删除我的数据吗？

+

当然可以，我们支持完整的数据删除：

  • 在设置中选择"数据管理"
  • 选择"删除所有数据"
  • 确认删除操作
  • 数据将被永久删除，无法恢复
  • 也可以选择删除特定类型的数据

💰 付费问题

出片手账是免费的吗？

+
