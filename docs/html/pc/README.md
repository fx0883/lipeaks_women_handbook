# 出片手账 PC端 UI设计

## 设计理念

基于手机端的设计风格，为PC端创建了响应式的用户界面，主要特点：

- **保持一致性**：延续手机端的温柔设计风格和配色方案
- **PC端优化**：采用左右分栏布局，充分利用大屏幕空间
- **响应式设计**：支持不同屏幕尺寸的自适应布局
- **交互优化**：针对鼠标操作优化了按钮大小和悬停效果

## 设计特色

### 布局系统
- **顶部导航**：固定位置，包含logo和主要导航链接
- **侧边栏**：280px宽度，包含分类导航和统计信息
- **主内容区**：自适应宽度，包含页面主要内容
- **工具栏**：底部固定，包含主要操作按钮

### 组件设计
- **卡片组件**：圆角、阴影、悬停效果
- **按钮系统**：主要、次要、幽灵、胶囊等多种样式
- **输入控件**：统一的圆角和焦点样式
- **选择器**：情绪、颜色、滤镜等专用选择器

### 响应式断点
- **1200px以下**：侧边栏变为顶部，编辑器变为单列
- **768px以下**：网格列数减少，间距调整
- **480px以下**：单列布局，移动端优化

### 交互效果
- **悬停动画**：卡片上浮、按钮变色
- **选择状态**：颜色选择器、情绪选择器的选中效果
- **过渡动画**：0.2s缓动效果，提升用户体验

## 技术实现

### CSS特性
- CSS Grid 和 Flexbox 布局
- CSS 变量定义主题色彩
- 媒体查询实现响应式
- 伪元素和变换实现动画效果

### 图片资源
- 使用 Unsplash 高质量图片
- 响应式图片尺寸（w参数）
- 统一的宽高比和圆角处理

### 交互脚本
- 简单的 JavaScript 交互
- 选择器状态管理
- 按钮点击效果

## 使用说明

1. 所有页面都引用了 `styles.css` 样式文件
2. 页面间通过相对链接进行导航
3. 响应式设计会自动适配不同屏幕尺寸
4. 交互效果需要 JavaScript 支持（已内置）

## 设计亮点

1. **温柔设计**：延续了手机端的治愈绿、樱花粉等温柔配色
2. **空间利用**：PC端充分利用大屏幕，提供更多信息展示
3. **操作便利**：侧边栏提供快速导航，工具栏提供主要操作
4. **视觉层次**：通过卡片、阴影、间距建立清晰的视觉层次
5. **一致性**：所有页面保持统一的设计语言和交互模式
